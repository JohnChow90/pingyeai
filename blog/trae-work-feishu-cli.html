一句话说清楚什么是飞书CLI

飞书CLI是专门给agent用的命令行工具，是agent和飞书之间的"翻译官"。官方给的定位是"给agent一双操作飞书的手"。

你在agent里用自然语言描述需求，飞书CLI把它翻译成飞书能听懂的操作指令，直接操控你的飞书消息、文档、表格、日程——不用你手动打开飞书App或网页，一句话搞定。

我挑了6个最常用的飞书CLI技能，外加自动化组合场景，展示一下飞书CLI能玩出什么花样。

技能名称作用/适用场景
lark-im收发消息、管理群聊，自动发送通知
lark-doc读写编辑飞书云文档，批量整理汇总
lark-sheets操作电子表格，自动填数据、做分析
lark-slides生成飞书幻灯片，快速做PPT
lark-base管理多维表格，项目任务跟踪
lark-calendar创建日程、预定会议室、管理参会人

使用之前必做：飞书授权

TRAE WORK已经内置了全套飞书CLI技能，不需要你手动安装，打开技能面板就能看到。但要能用能跑通，必须先完成飞书身份授权。

授权方法：TRAE WORK → 设置 → 外部应用授权 → 找到飞书 → 完成身份验证。

不授权会怎样？TRAE WORK仍然可以执行发消息、创建文档等操作，但无法访问你的个人数据（如你的日程、私信、收件箱）。

lark-im（飞书即时通讯）

每天早上自动给团队群发日报摘要，批量发送通知消息。自动整理群聊里的文件和关键信息。

用法：在TRAE WORK里说"给项目群发一条消息，通知大家下午3点开评审会"。

lark-doc（飞书云文档）

直接在TRAE WORK里写飞书文档，不用打开网页。批量读取多个文档做汇总。

用法："帮我把这3份会议纪要整理成一份汇总文档，保存到飞书"。

lark-sheets（飞书电子表格）

自动填数据、批量读取分析、写回结果。

用法："读取这个飞书表格里的销售数据，算出本月同比增长率，把结果写回表格最后一列"。

lark-slides（飞书幻灯片）

描述主题自动生成幻灯片，批量修改PPT，数据报告转PPT。

用法："帮我做一份项目汇报PPT，包含项目背景、进度、数据、风险4页"。

lark-base（飞书多维表格）

项目管理、批量导入导出。

用法："帮我把这个CSV文件导入到飞书多维表格，按'待办-进行中-已完成'分视图展示"。

lark-calendar（飞书日历）

创建日程、查会议室、批量导出。

用法："帮我查一下明天下午2点到4点，哪个会议室有空，然后创建一个评审会"。

组合拳：飞书CLI + 自动化

上面6个技能单独用已经很省时间，和TRAE WORK的自动化功能（Schedule）组合起来，才能实现"人不在，活照干"。

数据自动汇报

  1. 从后台导出当天数据
  2. 调用data-analysis技能自动分析
  3. 调用lark-base写入飞书多维表格
  4. 调用lark-im把链接发到飞书群聊

以前每天花40分钟手动干这些事，现在零操作。

总结

这6个飞书CLI技能，如果你公司用飞书，强烈建议都装上。飞书CLI最大的价值不是单个技能，而是和自动化组合之后的"无人值守"能力。

再次提醒：TRAE WORK预装飞书CLI，但必须先完成飞书授权。授权路径：设置 → 外部应用管理 → 飞书 → 身份验证。
